# GlobalPedia

Production-oriented Next.js 16 + React 19 + TypeScript knowledge platform.

## Visual direction
Dark navy interface, blue accent system, Earth/space hero, photographic article cards, world regions, responsive mobile navigation, and restrained motion inspired by the GlobalPedia reference designs.

## Run
npm install
npm run dev

## Build
npm run build

Image references use remotely hosted Unsplash images and should be reviewed before final commercial deployment.
